# Number Analyzer

## Project Overview
Number Analyzer is a beginner-friendly Python project developed using NumPy and Object-Oriented Programming (OOP). It helps users perform mathematical and statistical operations on arrays.

## Objectives
- Understand NumPy arrays.
- Learn classes and objects.
- Perform mathematical calculations.
- Analyze numerical data.

## Features
- Create 1D, 2D, and 3D arrays.
- Access array elements and perform slicing.
- Combine and split arrays.
- Perform addition, subtraction, multiplication, and division.
- Perform dot product and matrix multiplication.
- Sort, search, and filter array elements.
- Calculate sum, mean, median, and standard deviation.
- Find minimum, maximum, percentiles, and correlation.
- Menu-driven user interface.

## Technologies Used
- Python
- NumPy
- Object-Oriented Programming

## Requirements
Install NumPy using:

```bash
py -m pip install numpy
```

## How to Run

1. Save the code as `Number_Analyzer.py`.
2. Open the project in VS Code.
3. Open the terminal.
4. Run the following command:

```bash
py Number_Analyzer.py
```

5. Select an option from the menu.
6. Enter the required values.
7. Select Exit to close the program.
